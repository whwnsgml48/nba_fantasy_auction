# A/T 한계기여 모델

## 왜 필요했나

초기 평가에서 A/T를 **비율(A/T ratio)** 로만 판단해 `Luke Kornet 4.5` `Cam Spencer 4.3`
`Davion Mitchell 4.2` 같은 저볼륨 선수를 "$1~4에 A/T를 잠그는 카드"로 추천했습니다.

3PT%에서 이미 잡은 오류(rate만 보고 볼륨 무시)와 **완전히 같은 구조**인데 A/T에는 적용하지
않고 있었습니다. A/T도 `팀 총 어시스트 ÷ 팀 총 턴오버`라서 개인 비율이 아니라
**어시스트·턴오버 볼륨**이 팀 비율을 움직입니다.

## 계산

```
팀 A/T = ΣAST / ΣTOV
한계기여 = (A₀ + a) / (T₀ + t) − A₀/T₀

기준선: 나머지 6명 선발 합계 A₀ = 20.0 AST, T₀ = 10.0 TOV → 팀 A/T 2.00
```

### ⚠️ 기준선 실측 검증 (16차, 2026-08-20)

위 `A₀=20.0 · T₀=10.0`(슬롯당 AST 3.33 · TOV 1.67)은 **가정**이었습니다.
BBRef 전체 스탯으로 실제 상대 선발을 계산하니 더 높습니다:

| | 슬롯당 AST | 슬롯당 TOV | 6명 기준선 |
|---|---|---|---|
| docs/07 가정 | 3.33 | 1.67 | A₀ 20.0 · T₀ 10.0 |
| **실측** (지명 풀 126명 중 MPG≥25, 107명 평균) | **4.42** | **2.19** | **A₀ 26.5 · T₀ 13.2** |

**A/T 결론은 유효합니다.** 두 기준선으로 한계기여를 다시 계산해 비교한 결과
**가중치 보유자 37명의 순위 변동이 0칸**입니다. 절대값만 약 22% 축소됩니다
(Haliburton +0.517 → +0.405 · McConnell +0.261 → +0.202 · Jokić +0.241 → +0.192).

단, **한계기여가 음수로 넘어가는 선수가 4명 늘어납니다**
(Bam Adebayo · Gary Trent Jr. · Marcus Smart · Bub Carrington).
그중 A/T 가중치 보유자는 **Marcus Smart(w1)** 하나이고 값이 −0.002로 노이즈 수준입니다.
현재 `M2` 검증은 docs/07 기준선으로 일관 적용하므로 통과합니다.

→ 실측 기준선은 `cores.json`의 `opponent_baseline`에 단일 소스로 보관합니다.
**TOV 판정은 이 기준선을 씁니다** (아래).

## 두 가지 결론

### ① Haliburton 프리미엄은 정당하지만 이유가 달랐다
"A/T 5.75가 리그 최고"가 아니라 **"고어시스트(9.2)와 저턴오버(1.6)를 동시에 갖는 조합"**이
가치의 실체입니다. 한계기여 +0.517은 2위의 2.0배이고, 저볼륨 다트(+0.08~0.16)의 3~6배입니다.

### ② 저볼륨 A/T 다트는 과대평가였다
`Kornet 4.5` `Cam Spencer 4.3` `Davion Mitchell 4.2` `Quickley 4.1`은 전원
**4+APG 리더보드에 없습니다 = 어시스트 4.0 미달**. 어시스트 볼륨이 없으면 팀 비율을
거의 못 움직입니다. Kornet은 백업 센터라 실제 한계기여가 +0.08 내외로 추정됩니다
(Haliburton의 1/6). 해당 선수들에 `AST 볼륨 미확보` 플래그를 달았습니다.

### ③ 파생: A/T 분산 조달 경로 (코어 6)
```
McConnell (+0.261) + DeRozan (+0.152) = +0.413
Haliburton 단독          (+0.517)
→ 리프트의 80%. 아킬레스 리스크 소멸. 비용: 슬롯 2개 소모
```
가격은 코어 계획가 기준으로 계산하세요 — 현재 코어 6은 McConnell $4 + DeRozan $16 = **$20**,
Haliburton 단독은 코어 1에서 **$50**입니다 (`data/cores.json`).

⚠️ **A/T 리스크가 없는 것은 아닙니다** — McConnell은 인디애나 3번째 가드로 코어 6 A/T의 63%를
담당하고, DeRozan 대체안(Schröder +0.110 / D.Russell +0.017)은 질이 크게 떨어집니다.

## 한계

- **기준선 20.0/10.0은 추정치.** 실제 로스터 구성에 따라 달라지고, 빅맨 헤비 팀은
  A₀가 낮아져 같은 선수의 한계기여가 커집니다.
- **저볼륨 선수 6명의 AST 볼륨을 확보하지 못했습니다** (4+APG 리더보드 미포함).
  추정 상한만 기재했습니다.
- FG%·FT%는 시도량(FGA·FTA) 데이터가 없어 같은 계산을 못 했습니다.

# TOV 한계기여 (16차 추가)

A/T와 **같은 구조**입니다. TOV도 팀 총합 캣(`팀 TOV = Σ 선발 TOV`)이므로
개인 비율이 아니라 **볼륨이 팀 총합을 움직입니다.**

```
한계기여 = (상대 슬롯당 기대 TOV) − (내 선수 TOV)
기준선   = 2.193 / 슬롯  (지명 풀 126명 중 MPG≥25, 107명 평균)
양수 = 팀 TOV 총합을 줄임 = 캣에 도움
```

## 가중치 등급 (16차 체계화)

| 등급 | TOV | 한계기여 | 인원 |
|---|---|---|---|
| **w3 엘리트** | ≤ 0.8 | ≥ +1.39 | 23명 |
| **w2 플러스** | 0.9~1.2 | +0.99 ~ +1.29 | 25명 |
| **w1 약플러스** | 1.3~1.5 | +0.69 ~ +0.89 | 22명 |
| 미부여 | ≥ 1.6 | ≤ +0.59 | — |

등급 경계는 **자격 풀(GP≥40, 150명)의 중앙값 1.65**를 기준으로 잡았습니다.
w3 비율 13%는 타 캣(DD 13% · FG% 13% · 3PM 12% · AST 11%)과 같은 수준입니다.

> ⚠️ **TOV는 MPG와 상관 +0.717입니다.** 저출장 선수가 유리해지는 것은 이 캣의 구조적 성질이고
> (야후 H2H는 **선발만 집계**하므로 실제로 팀 총합을 낮춥니다), 전체 가치는 `my_max`가 담당합니다.
> 각 선수의 `tov_context`에 MPG·GP·한계기여를 함께 기록해 오독을 막습니다.

## 왜 "가중치 합 ≥ 6" 규칙으로는 판정이 안 되는가 🔴

**가중치는 1~3 양수뿐이라 "TOV를 흘리는 선수"를 음수로 표현하지 못합니다.**
`Jokić 3.7 TOV`는 팀 TOV를 크게 늘리는데 가중치가 0(미부여)이라 합계에 아무 영향이 없습니다.

실제로 두 지표가 어긋납니다:

| 코어 | 가중치 합(선발) | 실측 팀 한계기여 | 선언 |
|---|---|---|---|
| c1 | 3 | **+1.65** | 목표 ✅ |
| c2 | 6 | +1.25 | 포기 (그런데 이김) |
| c3 | 3 | +1.35 | 포기 (그런데 이김) |
| c4 | 1 | +0.75 | 포기 (그런데 이김) |
| c5 | 2 | **+1.75** | 목표 ✅ |
| c6 | 7 | **+2.35** | 목표 ✅ |
| c7 | 4 | **+1.35** | 목표 ✅ |

가중치 합 3인 c1이 합 6인 c2보다 실제로 더 좋습니다.
→ **판정은 `cores.json`의 `tov_team_marginal`을 쓰고, `validate.py`가 이를 검사합니다.**
`TOV`를 목표로 선언한 코어는 팀 한계기여가 양수여야 합니다(현재 c1·c5·c6·c7 전부 충족).

**부수 결론**: 빅맨 중심 코어는 TOV를 **의도하지 않고도 이깁니다**(빅맨은 TOV가 낮음).
c2·c3·c4의 "TOV 포기" 선언은 실측상 과도한 비관입니다.
