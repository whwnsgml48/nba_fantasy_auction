# 43차 사전 등록 — 순수가치 × GP 벌점 구조

> 🔴 **이 문서는 측정 **전에** 쓰고 커밋한다.** 24차 원칙(사전 고정 계수를 실측에 맞춰
> 튜닝하지 않는다)이고, 42차에 그 원칙이 세 번 작동했다. 형태를 먼저 고정하고 결과를 본다.
> 작성·커밋 2026-09-09 · 측정 착수 전.

---

## 0. 왜 여는가 — 사용자 지시

> *"스탯 기반으로 순수가치 측정하고 GP로 벌점 주는 구조가 맞을 것 같음."*

발화 지점은 **Dejounte Murray** 다. 경기당 `17.2P 6.1R 7.0A 1.8S · FT 84.1%` 인데
`my_max $3` · `dollar_naive $2` · **획득 불가**다. 혼합 GP 24.1 이 죽인다.

## 1. 🔴 확인된 구조적 결함 — **절단(censoring)이 한쪽으로만 걸린다**

혼합 GP 는 두 시즌을 GP 가중으로 섞는데, **0경기 시즌은 가중치 0 이라 자동으로 빠진다.**
그래서 **복귀해서 몇 경기라도 뛴 선수만** GP 가 깎인다:

| 선수 | 24-25 | 25-26 | 혼합 GP | |
|---|---|---|---|---|
| Haliburton | 73 | **0 (제외)** | **73.0** | 아킬레스 · 0경기라 **안 깎임** |
| Lillard | 58 | **0 (제외)** | **58.0** | 아킬레스 · 0경기라 **안 깎임** |
| **Tatum** | 72 | **16** | **58.0** | 아킬레스 · **16경기 뛰어서 −14** |
| Sabonis | 70 | 19 | 55.2 | |
| **D.Murray** | **31** | **14** | **24.1** | 두 시즌 다 절단 |

🔴 **Tatum 과 Haliburton 은 같은 부상 등급인데 「복귀해서 뛰었는가」가 GP 를 정한다.**
방향이 거꾸로다 — 복귀를 보여준 쪽이 벌을 받는다.

절단 관측(「14경기 뛰고 다쳤다」)을 완결 관측(「14경기 뛰는 선수」)처럼 평균에 넣은 것이고,
**한쪽 끝(0경기)만 우연히 제외되어 절단 처리가 비대칭**이다.

## 2. 채택할 구조 — **곱셈을 쪼갠다**

```
v_pure(i)  = Σ_c z_c(경기당 기여)              ← GP 를 안 섞는다. 「뛰면 무엇을 주나」
                                                 비율캣의 시도량 가중은 유지(실력의 일부다)
a(i)       = GP_i / 82                          ← 가용도. **한 곳에만 존재한다**
v_repl(A)  = 원형 A 의 **FA 대체 수준**         ← 풀 밖 실측에서 산출 (§6c 모집단)
value(i)   = v_pure(i)·a(i) + v_repl(A(i))·(1 − a(i))
```

읽는 법: **뛰는 날은 그 선수를, 결장일은 FA 대체를 얻는다.**
달러 환산은 현행과 같다(대체 수준 위 z 를 $2,674 에 비례 배분).

### 🔴 왜 이 형태인가 — **임의 상수가 하나도 없다**
조율 제안은 「벌점 함수 `g` 를 §6c 의 FA 깊이에서 유도하라」였다. 깊이(N명)를 벌점으로
바꾸는 사상함수를 만들면 그 사상 자체가 발명이 된다. 대신 **깊이의 원인을 직접 쓴다** —
「그 원형의 FA 가 실제로 무엇을 주는가」를 **재서** 넣는다. 그러면 §6c 의 결론이
자동으로 재현된다:

```
3PM 다트 (FA 25명)      v_repl 높다  → 결장 손실 작다 → 벌점 가볍다
OREB·BLK 빅 (FA 7명)    v_repl 낮다  → 결장 손실 크다 → 벌점 가혹하다
```
**§6c 가 문서에만 있던 것을 가치 모델이 쓰게 된다.** 그것이 이 작업의 핵심 이득이다.

### 사전 고정 규칙 (결과를 보고 바꾸지 않는다)

1. **FA 모집단**: BBRef 2025-26 583명 중 우리 174명을 뺀 419명, 그중 `GP≥30 · MPG≥15`
   (§6c 와 **같은 필터**). 재현 확인: 3PM 25 · STL 21 · OREB·BLK 7 · REB 13 · 고FG% 9
   — §6c 의 「미평가(하한)」 열(25·20·7·12·9)과 일치.
2. **`v_repl` 은 그 원형 FA 자격자의 `v_pure` 중앙값.** 최댓값이 아니다 —
   시즌 중 상위 FA 는 다른 13팀도 줍는다. **중앙값이 「실제로 잡을 수 있는 수준」**이다.
   ⚠️ 최댓값 판본은 **감도로 함께 보고**한다. 둘 중 고르지 않는다.
3. **원형 배정**: §6c 필터를 그대로 쓴다. 여러 원형에 걸리면 **FA 가 가장 얇은 원형**을
   쓴다(희귀 조합일수록 대체가 어렵다). 어디에도 안 걸리면 **전체 FA 자격자 중앙값**.
4. **`v_repl > v_pure` 이면 `v_repl := v_pure`** 로 자른다. **결장으로 이득을 볼 수는 없다.**
5. **z 표준화는 현행과 같은 모집단**(지명 풀 126명)에서 구한 평균·표준편차를 쓴다.
   FA 선수도 그 척도로 환산한다 — 두 값이 같은 자 위에 있어야 더할 수 있다.

## 2b. 🔴 수정 (2026-09-09 · **여전히 측정 전**) — 크레딧은 **결장의 형태**에 달렸다

§2 의 `v_repl·(1−a)` 는 **결장일에 FA 대체를 얻는다**고 가정한다.
**이 리그에서는 대개 못 얻는다.** `docs/01:306-312` 가 이미 갈라 놨다:

```
스트리밍   빈 칸을 돌려 주간 경기 수를 늘린다 → **여유 칸 필요** → 벤치 2칸이라 **불가**
교체       죽은 자산을 버리고 FA 를 줍는다   → 여유 칸 불필요   → **가능**
```
→ 크레딧이 붙는 조건은 **결장의 형태**다:
```
장기 결장(시즌 아웃·수술·IL)      드롭하고 FA 를 줍는다  → v_repl 이 맞다
산발 결장(로드 매니지먼트·1~3경기)  **칸이 그냥 빈다**     → 크레딧 **0** 이 맞다
```
Jokić 의 결장 17경기는 **산발**이다 — 그를 드롭하고 FA 를 줍지 않는다. 그 17경기에 얻는 것은
`v_repl` 이 아니라 **아무것도 없다.**

🔴 **방향이 위험하다.** 이 과대는 **결장 많은 선수를 실제보다 좋게** 만든다.
사용자 질문(Murray 가 너무 싸다)의 답 방향과 같아서 **맞아 보이지만**, 같은 크레딧이
Jokić·Wemby·AD 처럼 **산발 결장하는 비싼 선수**에게도 붙는다 — 42차가 불신하기로 배운
쪽이 또 좋아 보인다.

### 그래서 **두 극단을 다 잰다** (결장 형태 실측은 게임로그가 필요하고 26일 안에 할 일이 아니다)

```
현행    z(경기당 × a) 를 합산                    ← GP 가 z 표준화 **안쪽**
변형 B  z(경기당) 합산 × a                       ← 칸이 빈다 (무크레딧)
변형 A  z(경기당) 합산 × a + v_repl·(1−a)        ← 항상 교체 가능 (전액 크레딧)
```
⚠️ **B 는 현행과 다르다.** 현행은 GP 를 섞은 뒤 표준화하므로 σ 에 **실력 분산과 출장 분산이
같이** 들어간다. B 는 실력 분산만 들어간다 — **z 의 의미가 다르다.**
세 판본을 다 내면 「표준화 변경」과 「크레딧 도입」의 효과가 **분리돼서** 보인다.

**판정 규칙(사전 고정)**
- A 와 B 의 **순위가 같으면** 이 질문은 답할 필요가 없다 → A 채택 + 「B 에서도 같다」를 근거로.
- **갈리면** 갈리는 선수 목록이 곧 **「결장 형태를 알아야 하는 선수」**다.
  그 목록만 손으로 판정한다(`flag`·`injury_exclude`·`measured_source` 에 이력이 있다).
  **전수 측정이 아니라 갈리는 것만.**
- ⚠️ **`censored` 두 번인 선수(Murray)에게는 A 에서도 크레딧을 주지 않는다.**
  `a` 자체가 「추정 불가」인데 없는 `a` 로 크레딧을 계산하면 **가짜 확신이 두 번 겹친다.**

### 달러 환산 — **이중 차감** 확인 (사전 등록)
새 구조에서는 모든 선수가 `v_repl·(1−a)` 라는 **바닥을 이미 갖는다.** 거기서 또 126위를
빼면 대체 수준이 두 번 들어간다. 반드시 확인할 것:
- 새 `value` 분포에서 **126위가 어디인가**
- **총액 $2,674 가 보존되는가** — 안 되면 어디서 새는지 적는다.
  **총액이 안 맞으면 개별 달러는 비교 불가다.**

## 3. 절단 처리 — **GP 추정은 이번에 바꾸지 않는다**

절단 시즌을 GP 추정에서 빼는 것이 가장 깔끔해 보이지만 **부작용이 위험하다**:
```
Sabonis 55.2 → 70 · Tatum 58 → 72 · Murray 24.1 → ?
→ 이 수정은 **아킬레스 복귀 선수들의 GP 를 계통적으로 올린다**
→ c1·c3·c5 가 좋아 보이게 된다. 42차가 불신하기로 배운 바로 그 베팅들이다.
```
그래서 **드러내기만 한다**:
- `measured_source.seasons[].censored` 불리언 신설 + 판정 근거 문자열.
- **두 시즌 다 절단이면 GP 를 「추정 불가」**로 둔다(점 추정을 만들지 않는다).
  `$3` 이라는 **가짜 확신**보다 「모른다」가 낫다.
- 「추정 불가」는 벌점에서 **점이 아니라 밴드**로 처리하고 **P1 출장 확인 대상으로 승격**한다.

## 4. 🔴 건드리지 않는 것

- **팀 총량 경로** — `cat_model.marginal()` · `baselines()` · `matchup_sim`.
  거긴 `Σ(경기당 × 그 주 경기수)` 이고 **곱셈이 물리적으로 맞다.** 여기를 건드리면
  42차의 모든 승률이 무효가 되고 26일 안에 회복 못 한다.
- **`my_max`** — 덮지 않는다. `value_reference` 는 **대조선**이다.
  바뀌는 것은 M5·M6 판정이고 그건 예상된 파급이다.
- 옛 경로는 **지우지 않고 비교용으로 남긴다.**

## 5. 채택 기준 — **먼저 적는다**

1. **기전 설명 가능성.** 순위가 바뀌면 그 방향이 구조로 설명돼야 한다:
   - 고GP · 얇은 원형 → **오른다**
   - 저GP · 깊은 원형 → **오른다**(결장일을 FA 로 메운다)
   - 저GP · 얇은 원형 → **내린다**
2. **20계단 이상 이동 중 기전으로 설명 안 되는 것이 과반이면 → 기각.**
3. **백테스트**(가능하면): `docs/05 §2b-7` 하네스로 24-25 정보 → 25-26 채점.
   **정직한 조건에서 새 구조가 옛 구조를 못 이기면 그게 답이다.**
4. `validate.py` 0건 · 음성 테스트 통과.

🔴 **결론이 「바꾸지 말자」여도 그것이 결론이다.** 42차에 두 번 그랬고 둘 다 옳았다.
