## 4. 예산 — 규칙 두 줄 (확보 **순서와 무관**하게 성립한다)

```
① 최대 입찰   = 잔액 − (남은 칸 − 1)          마지막 칸까지 $1 은 남긴다
② 안전선     잔액 ≥ **남은 칸들의 계획가 합**   이보다 적으면 이미 뒤처졌다
```
**②의 계획가는 §2 표에서 읽는다** — 남은 칸의 「계획」 열을 더하면 된다.

| 남은 칸 (예) | 계획가 합 | 잔액이 이보다 적으면 |
|---|---|---|
| C·PG·PF·SG·BN·UTIL·SF·BN·UTIL (9) | $191 | 시작부터 부족 |
| PF·SG·BN·UTIL·SF·BN·UTIL (7 · 큰 둘 확보) | $107 | 🔴 |
| SF·BN·UTIL (3 · 여섯 확보) | $21 | 🔴 |
| UTIL (1) | $5 | 🔴 |

> ⚠️ **「3명 확보 시 $90」 같은 고정 체크포인트는 쓰지 마라.** 싼 칸을 먼저 채우면
> 같은 3명이라도 잔액이 전혀 다르다. **남은 칸 기준**이 순서에 무관하다.

### 🔴 이미 안전선을 깼다면
```
KAT 을 아직 안 샀다   → 감축 ①(KAT→Duren) 을 지금 쓴다. $63 이 풀린다
KAT 을 이미 샀다      → 감축 ①은 **없다.** 남은 칸을 §2 의 대체 사슬 **맨 아래**로 내린다
                        (Gobert→M.Williams · DeRozan→Wiggins · Edgecombe→Hart)
                        그래도 모자라면 **빈 칸으로 끝낸다.** $1 짜리를 억지로 채우지 않는다
```
🔴 **계획 예비($9)는 실탄이 아니다.** 7코어 중 **6개**가 작년 가격 기준으로 예비가
**마이너스**다(c6 −$76). 여유가 있다고 생각하고 부르면 중간에 돈이 떨어진다.

## 6. 그 자리에서 답할 것

- **못 사는 값이 나왔다** → 대체로 내려간다. 대체도 상한 위면 **그 칸을 버린다.**
- **계획에 없는 선수가 싸게 나왔다** → 산다. 단 **남은 칸의 포지션 자격**을 먼저 본다.
- **자동 $1 입찰이 있다** — 태우기 지명은 **남이 100% 붙을 선수만.**
- 지명은 **순번 로테이션**이다. 내 차례는 반드시 온다 — 급하게 지명하지 않는다.
