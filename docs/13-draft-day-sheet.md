> **A4 한 장.** 넘기면 실패다. 여기 없는 숫자는 드래프트 중에 보지 않는다.
> 승률·p³·가정취약성·캣가중치·z 는 **일부러 뺐다** — 그날 「부르거나 물러난다」에 안 쓴다.
> 화면(콘솔)은 보조다. **탭이 죽어도 이 종이로 끝까지 간다.**
> 42차 (2026-09-08) · 근거 `docs/05 §13~§15` · 검증 `validate.py` · `tool/winnable.py`
>
> 🔴 **「방」 = 이 방이 작년에 실제로 낸 값**(×1.117 환산). 추정이 아니라 **관측**이다.
> 표본은 **한 해**다 — 「올해도 그 값」이 아니라 **「작년처럼 가면 이렇다」**로 읽는다.

## 4. 예산 — 규칙 두 줄 (확보 **순서와 무관**)

```
① 최대 입찰  = 잔액 − (남은 칸 − 1)          마지막 칸까지 $1 은 남긴다
② 안전선     잔액 ≥ **남은 칸들의 계획가 합**  (§2 「계획」 열을 더한다)
```
| 남은 칸 (예) | 계획가 합 |
|---|---|
| 아홉 전부 | $191 |
| 큰 둘(C·PG) 확보 후 일곱 | $107 |
| 여섯 확보 후 셋(SF·BN·UTIL) | $21 |
| 마지막 하나 | $5 |

### 🔴 안전선을 깼다면
```
KAT 미보유  → 감축 ①(KAT→Duren). $63 이 풀린다. **이것이 유일한 사전 등록 수단이다**
KAT 보유    → 🔴 **c6 안에 더 줄일 곳이 없다.** 남은 대체는 못 사거나 더 비싸다.
              → 계획 **밖**에서 남은 예산으로 살 수 있는 선수를 줍는다(포지션 자격 먼저)
              → 그래도 안 되면 **빈 칸으로 끝낸다.** $1 짜리를 억지로 채우지 않는다
```
🔴 **계획 예비($9)는 실탄이 아니다.** 7코어 중 **6개**가 작년 가격 기준 예비 **마이너스**다

## 6. 그 자리에서 답할 것

- **못 사는 값이 나왔다** → 대체로 내려간다. 대체도 상한 위면 **그 칸을 버린다.**
- **계획에 없는 선수가 싸게 나왔다** → 산다. 단 **남은 칸의 포지션 자격**을 먼저 본다.
- **자동 $1 입찰이 있다** — 태우기 지명은 **남이 100% 붙을 선수만.**
- 지명은 **순번 로테이션**이다. 내 차례는 반드시 온다 — 급하게 지명하지 않는다.
