# 리그 세팅 · 13캣 구조 분석

## 리그 규칙 (사용자 제공)

- **14팀** · Yahoo Fantasy Basketball 사설 · **H2H Categories**
- **13캣**: `PTS FG% 3PTM 3PT% FT% REB OREB AST STL BLK DD A/T TOV`
  - 사용자 원문에 `PG%`로 적혀 있었으나 Yahoo 카테고리 목록에 존재하지 않아 `FG%` 오타로 판단
- **로스터 9명**: PG SG SF PF C + UTIL×2 + BN×2 → **선발 7 / 벤치 2**
- **IL+ 1칸**: Yahoo 기준 IL+는 `INJ`/`OFS` 외에 `O`(7일 미만 결장·출전정지), `GTD` 수납 가능.
  `Q`(Questionable)는 공식적으로 IL+ 대상 아님 — 다만 Yahoo NBA는 대개 GTD로 표기
- **옥션**: 전원 $200 · 최소 입찰 $1 · 최종 입찰 후 10초 무경쟁 시 자동 낙찰 ·
  **직전 낙찰자가 다음 선수 지명** · 전원 9명 낙찰 시 즉시 종료

## 13캣의 구조적 특징

### 표준 9캣 대비 추가된 4캣
`OREB` `DD` `3PT%` `A/T` — **모든 아비트라지는 이 4개에서 나옵니다.** 시장 가격은
9캣 기준으로 형성되므로, 이 4캣 공급원이 체계적으로 저평가됩니다.

### 캣 분류

| 종류 | 캣 | 개수 |
|---|---|---|
| **합계**(팀 총량 비교) | PTS 3PTM REB OREB AST STL BLK DD TOV | **9** |
| **비율**(팀 효율 비교) | FG% 3PT% FT% A/T | 4 |

합계 캣은 달러당 생산이 중요 → 중저가 구간이 유리.
비율 캣은 **시도량 지분**만큼만 레버리지 → 저볼륨 고효율은 기여가 작고 변동성이 큼.
(자세한 계산: `03-player-valuations.md`)

### 공급원별 분류

| 공급원 | 캣 | 개수 |
|---|---|---|
| 빅맨 우세 | FG% REB OREB BLK DD | 5 |
| 가드/윙 우세 | 3PTM 3PT% FT% AST STL A/T | 6 |
| 중립 | PTS TOV | 2 |

13캣이므로 **7캣 승리**가 목표.

### 🔴 「포맷이 빅맨을 선호한다」는 오독입니다 (39차 정정)

위 표(빅 5 · 가드 6)를 보고 *"13캣은 빅맨 포맷"* 이라고 읽으면 안 됩니다. **반대로도 아닙니다.**

**추가된 4캣이 정확히 2대 2로 갈립니다** — `OREB`·`DD`는 빅, `3PT%`·`A/T`는 가드입니다.
아비트라지의 원천이 양쪽에 반씩 있으므로 **포맷 자체는 중립**입니다.

같은 예산($188)에서 C 자격 수만 강제하고 각각의 천장을 측정한 결과:

| 구성 | C 자격 | 평균 | 최저 |
|---|---|---|---|
| 빅 헤비 | 5~6명 | 91.1% | 80.9% |
| **균형** | **3~4명** | **91.6%** | **81.4%** |
| 가드 헤비 | 1~2명 | 89.1% | 79.2% |

> 측정 출처: 39차 평가 세션. **이 세션이 독립 재현하지 않았습니다** — 재현하려면
> C 자격 수를 제약으로 넣고 `tool/c2_search.py` 형태의 탐색을 세 번 돌리면 됩니다.

**빅 헤비와 균형이 0.5%p로 사실상 동률**입니다. 빅맨이 유리한 것이 아니라
**가드로 너무 쏠리면 안 되는** 것뿐입니다. 그리고 세 로스터가 하단
(`Gobert $8` · `Okongwu $5` · `Vučević $2` · `Hart $4`)을 **공유**합니다 —
바뀌는 것은 상단이고 하단은 같습니다.

### 정확한 명제

> **포맷은 중립이다.** 편향을 만드는 것은 **이 리그의 가격**이다 —
> `docs/08` 실측대로 센터 지출의 **77%가 네임밸류 빅 11명**에게 가고
> 나머지 **23명이 평균 $8.2**에 방치된다.
> **$2~8 구간의 생산형 빅이 유일하게 값이 매겨지지 않은 자원**이다.

이번 라운드 측정들이 전부 이것을 지지합니다:
- c6 수리가 `Clingan(빅) → Bane(전방위 윙)`으로 **+3.1%p**였습니다 — 빅을 하나 뺐는데 올랐습니다
- Bane 슬롯 21명 실측에서 상위권이 **전방위 윙**이었고, $2 3PT 스페셜리스트는 아래였습니다
- 최강 코어 c2(88.9%)는 C 자격 5명이지만 그중 넷이 **$12 이하**입니다

### 🔴 왜 이 구분이 드래프트 당일에 중요한가

**저가 빅이 과열되면(= 우선 0 발동 조건) 그 잉여가 사라집니다.** 그때
*"포맷이 빅을 선호한다"* 고 알고 있으면 **비싼 빅을 쫓게 됩니다.** 정확한 대응은
**균형을 유지한 채 상단을 바꾸는 것**이고, `c7`의 「중가 센터 전환」이 이미 그 대응입니다.

즉 c7은 "센터를 더 사는 플랜"이 아니라 **"싼 빅이 사라졌을 때 같은 균형을 다른 가격대에서
만드는 플랜"** 입니다. 이 근거가 지금까지 문서에 없었습니다.

## 핵심 주장 3개 (평가 대상)

### ① TOV와 A/T는 서로 반대 방향 캣

A/T는 **팀 총 어시스트 ÷ 팀 총 턴오버**로 계산됩니다. 따라서:
- 빅맨 몰아담기 → 턴오버 적어 TOV는 이기지만 어시스트가 없어 **A/T는 짐**
- 볼도미넌트 가드 몰아담기 → AST/A/T는 이기지만 **TOV는 짐**

→ **둘 중 하나는 거의 자동으로 내주는 구조.** 동시에 이기는 유일한 방법은
"어시스트 많고 턴오버 적은 가드" 확보.

실측 검증 (2025-26, 어시스트 4.0+ 그룹은 25명뿐):

|---|---|---|---|
| T.J. McConnell | 5.1 | 1.1 | **4.64** |
| Derrick White | 5.4 | 1.7 | **3.18** |
| Jamal Murray | 7.1 | 2.3 | **3.09** |
| Jimmy Butler III | 4.9 | 1.6 | 3.06 |
| Nikola Jokić | 10.7 | 3.7 | 2.89 |
| Cade Cunningham | 9.9 | 3.7 | 2.69 |
| Luka Dončić | 8.3 | 4.0 | **2.08** |
| Giannis | 5.4 | 3.2 | **1.69** |
| Stephen Curry | 4.7 | 2.8 | **1.68** |
| Kevin Durant | 4.8 | 3.2 | **1.50** |
| Jaylen Brown | 5.1 | 3.6 | **1.42** |

Haliburton은 2025-26 전체 결장. 직전 시즌(2024-25) 9.2 AST / 1.6 TOV = **A/T 5.75**,
커리어 4.14(첫 5시즌 기준 CP3 3.88·스탁턴 3.74 상회). 이 포맷에서 TOV와 A/T를
동시에 이기는 거의 유일한 고볼륨 가드.

⚠️ 저볼륨 저턴오버 롤플레이어(Dean Wade 5.5, Luke Kornet 4.5 등)가 A/T 리더보드
상위에 오르므로, A/T는 "턴오버 적은 빅맨"이 아니라 "어시스트 많은 가드"로 이기는 캣.

### ② OREB·DD·BLK는 공급자가 극소수 → 최저가 승점

OREB 리그 상위 25명 중 9캣 top-50에 든 선수는 **6명뿐**(Jokić, KAT, Duren, Şengün,
Amen Thompson, Mobley). 나머지 19명은 전부 $1~16 구간.

| 캣 | 최상위 공급자 | 예상 시장가 |
|---|---|---|
| OREB 4.5 (리그 1위) | Donovan Clingan | $9~18 |
| OREB 4.2 (리그 2위) | Mitchell Robinson | $5~12 |
| OREB 3.9 + BLK 1.6 + DD 33 | Rudy Gobert | $8~16 |
| OREB 3.7 + DD 20 | Moussa Diabaté | $1~3 |
| BLK 1.9 (리그 3위) | Jay Huff | $1~3 |

→ **REB·OREB·BLK·DD 4캣을 $50 이하로 잠글 수 있음.**
비싼 건 "빅맨 캣"이 아니라 "빅맨 캣 + PTS/FT%/3PTM을 한 몸에 주는 선수"이고,
후자는 살 필요가 없음(가드에서 싸게 조달).

### ③ 포지션 고정이 강한 제약

플렉스(G/F) 슬롯이 없음 → 진짜 PG·SG·SF·PF·C가 각 1명 이상 필요.
- **C 자격 최소 2명 필수** (C 1칸 + UTIL). 1명이면 결장 시 슬롯이 그냥 빔
- **F 자격 최소 2명 필수** (SF + PF). 빅맨을 C-only로만 채우면 SF/PF를 못 채움
  → 실제로 초기 코어 2안이 이 오류를 포함하고 있었음 (`04-audit-log.md` 참조)
- 벤치 2칸 = 스트리밍 사실상 불가 → 드래프트에서 출장 안정성 비중 상승
- 선발 7명 × 주간 경기수 = 카운팅 캣 총량 → 주간 스케줄 관리가 승패에 직결
