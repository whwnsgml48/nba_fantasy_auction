# 옥션 전략

## 1. 기본 수학

**예산 $200 / 슬롯 9개 → 선수당 평균 $22.2**
표준 13인 리그($15.4)보다 44% 높음. 표준 가치표를 그대로 쓰면 초반에 계속 물러나다가
$120 남기고 슬롯 4개로 끝남.

**최대 입찰 공식**
```
최대 입찰액 = 남은 예산 − (남은 슬롯 − 1)
```

**단일 최고 경고 지표: 잔여 슬롯당 예산 = 남은 예산 ÷ 남은 슬롯**
- $8 미만 → 위험(선발이 대체선수급으로 채워짐)
- 슬롯 4개 이하에서 $36 초과 → 미소진(잔여 풀에 쓸 곳이 없음)

## 3. "직전 낙찰자가 다음 지명" 룰 활용

표준 Yahoo 옥션(순번 로테이션)과 다르므로 명확한 활용법이 있음.

**① 지명권이 오는 타이밍 = 내 지갑이 가장 얇은 순간**
낙찰 직후 지명권이 옴 → 원하는 선수를 올리면 안 됨. 대신 "남들 예산 태우는 선수"를 올림.
태우기 대상: **이름값 높고 13캣 가치 낮은 선수** (명단은 `03-player-valuations.md`)

**② 연속 낙찰 = 연속 지명권 = 흐름 지배**
계속 지기만 하면 지명권을 한 번도 못 쥠 → 초반에 최소 한 명은 확실히 따서 흐름 확보.
값싼 빅맨(Clingan/Gobert 급)을 초반에 잡으면 지명권과 잉여를 동시에 얻음.

**③ 엔드게임 지명권 = 잔여 최고 선수 선점권**
후반에 $1~2 선수를 저격해 따면 지명권이 계속 옴. 남들이 파산했을 때 원하는 선수를
직접 올려서 최저가로 가져올 수 있음.

⚠️ **드래프트 전 확인 필수:** Yahoo는 통상 지명 시 지명자에게 **자동 $1 입찰**이 걸림.
이 룰이 맞으면 태우기 지명은 반드시 남들이 100% 달려들 선수여야 함. 애매한 선수를
올렸다가 아무도 안 붙으면 슬롯 하나가 $1에 날아가고, 슬롯이 9개뿐이라 표준 리그보다
훨씬 아픔.

## 4. 10초 룰 대응

- **10초는 계산할 시간이 아님.** 사전에 선수별 최대가 시트가 있어야 함 → `tool/`
- **점프 비딩으로 끊기**: $30→$31 대신 $30→$43. 코어 타겟에는 잔금 싸움을 피함
- **8~9초 스나이핑**은 남의 타겟을 흔드는 데 사용. 10초가 리셋되므로 내 타겟에는 금물

## 5. 경매 순서 전략

1. **초반(엘리트 빅맨 구간): 참여 안 함.** 이때 태우기 지명으로 예산 소모 유도
2. **초중반: 엘리트 가드/윙 확보.** 남들 예산이 빅맨에 묶여 있는 동안이 유일한 창구.
   이 타이밍을 놓치면 후반에 잔여 예산이 가드로 몰려 가드도 비싸짐
3. **중반: $10~31 잉여 구간이 진짜 승부처.** 여기서 $6 아끼려고 물러나면 빌드가 무너짐
4. **후반: $1~4에 Diabaté·Kornet·Jay Huff·McConnell 급이 남음.** 경쟁 없음
