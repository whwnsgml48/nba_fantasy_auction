## 1. 기본 수학

**예산 $200 / 슬롯 9개 → 선수당 평균 $22.2**
표준 13인 리그($15.4)보다 44% 높음. 표준 가치표를 그대로 쓰면 초반에 계속 물러나다가
$120 남기고 슬롯 4개로 끝남.

**최대 입찰 공식**
```
최대 입찰액 = 남은 예산 − (남은 슬롯 − 1)
```

**단일 최고 경고 지표: 잔여 슬롯당 예산 = 남은 예산 ÷ 남은 슬롯**
- $8 미만 → 위험(선발이 대체선수급으로 채워짐)
- 슬롯 4개 이하에서 $36 초과 → 미소진(잔여 풀에 쓸 곳이 없음)

## 3. 지명권 — 순번 로테이션 (2026-09-01 규칙 변경)

🔴 **이 절은 전면 교체됐다.** 종전 규칙은 "직전 낙찰자가 다음 지명"이었고, 이 절의 세 항목은
전부 그 전제 위에 있었다. 지금은 **순번 로테이션**이다 (순서는 당일 추첨).

### 무효가 된 것

| 종전 주장 | 왜 무효인가 |
|---|---|
| ① 지명권이 오는 타이밍 = 내 지갑이 가장 얇은 순간 | 지명은 **매수와 무관**하게 순번으로 온다 |
| ② 연속 낙찰 = 연속 지명권 = 흐름 지배 | 낙찰해도 지명권이 오지 않는다 |
| ③ 엔드게임에 $1 선수를 저격해 지명권을 계속 확보 | 순번이 고정이라 불가능 |

②의 따름 결론이었던 *"값싼 빅맨을 초반에 잡으면 지명권과 잉여를 동시에 얻는다"* 도
**잉여만 남는다.** 초반 저가 빅 확보의 근거는 여전히 유효하지만 이유가 하나 줄었다.

### 대체하는 것

**① 내 지명 9회의 시점을 미리 안다 — 태우기를 스케줄할 수 있다**

14팀 로테이션에서 내 순번이 p 번이면 내 지명은 전체 p, p+14, p+28 … 로 **총 9회**다.
종전 규칙에서는 지명권이 언제 올지 알 수 없어 태우기 대상을 "다음에 올 때 아무거나"로
써야 했다. 지금은 **9개 슬롯에 미리 배분**할 수 있다.

```
지명 1~2회차 (초반)   엘리트 빅 구간 — 이름값 최상급을 태운다 (Dončić·Edwards 급)
지명 3~5회차 (중반)   내 코어와 경쟁하는 포지션의 과대평가 선수
지명 6~9회차 (후반)   ⚠ 여기가 위험 구간 — 아래 ② 참조
```

**② 🔴 지명을 피할 수 없다 — 이게 새로 생긴 위험이다**

종전에는 낙찰하지 않으면 지명 의무도 없었다. 지금은 **내 차례가 무조건 온다.**
여기에 **지명 시 자동 $1 입찰**이 겹치면:

> 예산이 바닥이거나 남은 슬롯이 특정 포지션용으로 예약돼 있을 때 차례가 오면,
> 아무도 안 붙는 선수를 **$1에 떠안고 그 슬롯을 잃는다.**

→ 태우기 명단과 별개로 **"떠안아도 되는 선수" 목록을 미리 정해 둬야 한다.**
   후반 지명에는 태우기 대상이 아니라 **내가 $1에 받아도 손해가 아닌 선수**를 올린다.
   `03-player-valuations.md` 의 `$1~4 다트` 구간이 그 후보다.

**③ 🔴 로스터가 꽉 찬 팀이 빠지면 내 지명 빈도가 올라간다**

로테이션에서 9명을 채운 팀은 지명하지 않는다(확인 필요 — 아래 참조). 전체 지명 횟수는
126회로 고정이므로, **내가 늦게까지 슬롯을 남기면 내 지명 차례가 9회보다 많아진다.**

| 상황 | 내 지명 횟수 |
|---|---|
| 전원 비슷하게 채움 | 9회 |
| 내가 슬롯을 가장 늦게까지 남김 | 9회보다 **많다** — 로테이션이 짧아진 만큼 |

②와 합치면: **후반에 슬롯을 많이 남겨두는 전략의 비용이 올랐다.** 태우기 기회가 늘어나는
것은 이득이지만, 자동 $1 노출도 같이 늘어난다. 남길 거면 ②의 목록을 반드시 준비한다.

**④ 순번 위치에 정보 가치가 있다**

1라운드에서 앞 순번이면 **시장이 아직 가격되지 않은 상태**에서 지명해야 한다 (정보 열위).
뒤 순번이면 앞선 낙찰가를 보고 태울 선수를 고를 수 있다. 추첨 결과가 나오면
`06-` 의 시장 온도계 판정 시점을 그에 맞춰 당기거나 미룬다.

### ✅ 확정 (2026-09-02 사용자 확인)

**로스터 9명을 채운 팀은 로테이션에서 빠진다.** → 위 ③이 **확정된 위험**이다.
후반에 슬롯을 남기면 내 지명 차례가 9회보다 확실히 많아진다.

### 🔴 미결 — 리그 논의 중: 스네이크 여부

라운드마다 순서를 뒤집는지(1→14, 14→1, …) 아직 정해지지 않았다. **이건 ④를 크게 바꾼다.**

| | 단순 순환 | 스네이크 |
|---|---|---|
| 내 지명 간격 | **일정** (매 14번째) | **불균등** — 위치에 따라 갈린다 |
| 양 끝(1·14번) | 다른 위치와 동일 | **연속 두 번 지명** 후 장기 대기 |
| 중앙(7·8번) | 동일 | 단순 순환과 거의 같다 |

**끝 순번을 뽑았을 때 스네이크는 양날이다.**
- 이득: **연속 두 번 태우기** — 남들 지갑이 두꺼운 초반에 비싼 선수 둘을 연달아 올릴 수 있다
- 손해: 후반에 **연속 두 번의 강제 지명** — ②의 자동 $1 위험을 두 번 연달아 맞는다

간격을 계산하면 순번 k(1-based)의 지명 간격은 `29-2k` 와 `2k-1` 이 번갈아 온다.
k=1 이면 27 → 1 → 27 … 로 극단적이고, k=7 이면 15 → 13 로 거의 균등하다.

**따라서 추첨 결과에 따라 대응이 달라진다:**
- **끝 순번 + 스네이크** → 초반 연속 지명을 태우기에 몰아넣고, 후반 연속 지명용
  "$1에 받아도 되는 선수"를 **2명 연속으로** 준비한다
- **중앙 순번 + 스네이크** → 단순 순환과 같이 취급한다
- **단순 순환** → ①의 균등 배분(초반 2 / 중반 3 / 후반 4)을 그대로 쓴다

진행 툴(`~/personal_work/nba_draft`)은 **양쪽을 지원**한다 — `팀 설정` 의 스네이크
체크박스로 고른다. 당일에 정해져도 코드를 고칠 필요가 없다.
