카드가 각 행을 **충족 / 불가 / 미정 / 기본값**으로 실시간 판정하고 강도(`선택`/`견고`)를 함께 띄웁니다. 선택한 코어의 `계획 여유`는 상단 바에 있습니다.

**충족이 2건 이상이면 툴이 고르지 않고 나란히 보여줍니다.** 조립 불가한 쪽에 표시가 붙으니 그걸 보고 직접 고르십시오.

## 세 가지만 기억하십시오

**① 10초 안에 계산하지 마십시오.** 최대가는 화면에 있습니다. `입찰 한도`(하드 상한)와 `계획 여유`(이 코어를 유지하려면 남겨야 할 돈) 두 숫자만 보고 부르거나 물러나면 됩니다.

**② 타팀 낙찰가를 계속 기록하십시오.** 3명이 넘으면 `시장가 보정` 계수가 뜨고, `보정 적용`을 켜면 목록의 시장가·잉여·획득가능 판정이 실제로 재계산됩니다. **초반 5~10명이 가장 중요합니다.**

**③ 초반 엘리트 빅맨 경매에는 참전하지 마십시오.** 지명권이 오면 태우기 지명으로 남의 예산을 소모시킵니다.

```
태우기 순서 — 이름값은 높고 13캣 가치는 낮은 선수
Luka Dončić → Anthony Edwards → Giannis → Kevin Durant → Kawhi Leonard → Jaren Jackson Jr.
```

⚠️ 이 리그는 **지명 시 자동 $1 입찰**이 걸립니다. 태우기 대상은 반드시 **남들이 100% 달려들 선수**여야 합니다. 아무도 안 붙으면 $1에 떠안고 9칸 중 하나를 버립니다.

## 지명권 활용

이 리그는 **직전 낙찰자가 다음 선수를 지명**합니다(야후 기본값 아님).

- 낙찰 직후 지명권이 오므로 **원하는 선수를 올리면 안 됩니다** — 지갑이 가장 얇은 순간입니다
- 초반에 싼 빅(Gobert·Clingan급)을 하나 따두면 **지명권과 잉여를 동시에** 얻습니다
- 후반에 $1~2 선수를 저격하면 지명권이 계속 오고, 남들이 파산했을 때 원하는 선수를 최저가로 가져올 수 있습니다

# 코어 7종

시장 상황에 따라 **하나만** 짓습니다. 강도는 작년 이 리그 12팀의 실제 로스터를 상대로 측정한 주간 승률입니다(`data/matchup_sim.json` · 6000시행 · seed 20261020 — **툴 화면과 같은 값**).

| 코어 | 성격 | 평균 | 최저 | 조건 |
|---|---|---|---|---|
| **c2** | Jokić 앵커 | **88.9%** | 74.1% | Jokić ≤ $97 · ⚠ Jokić 67경기 가정 |
| **c6** | 전방위 윙 · **정상 시장 기본값** | **87.5%** | 71.6% | 없음 |
| c1 | KAT + Haliburton | 86.8% | 72.8% | KAT ≤ $50 · Hali ≤ $56 · ⚠ Hali 73경기 가정 |
| c7 | 중가 센터 전환 | 86.4% | 70.3% | 저가 센터 2명+ 과열 |
| c5 | Sabonis 부상 할인 | 84.5% | 68.8% | 건강 확인 |
| c4 | 무앵커 분산 (상한 $31) | 84.3% | 68.9% | 앵커 실패 |
| c3 | SGA 앵커 | 84.1% | 68.6% | SGA ≤ $85 · ⚠ Lillard 투영 GP |

각 코어에 **과열 피벗**이 딸려 있습니다 — 계획한 저가 센터가 비싸지면 툴이 교체안을 띄웁니다.

`평균`이 코어 선택 기준이고 `최저`는 견고성 참고입니다. 두 값이 다른 코어를 가리킬 수 있으니 **고를 때는 평균을 보십시오.**

## 이 포맷의 핵심

13캣이 표준 9캣에 더한 것은 `OREB · DD · 3PT% · A/T` 넷입니다. **빅 2 · 가드 2로 갈리므로 포맷 자체는 중립입니다.**

편향은 **이 리그의 가격**에서 나옵니다 — 작년 실측상 센터 지출의 77%가 네임밸류 빅 11명에게 가고 나머지 23명이 평균 $8.2에 방치됐습니다.

> **$2~8 구간의 생산형 빅이 이 방에서 유일하게 값이 안 매겨진 자원입니다.**

그래서 어떤 코어든 그 구간을 3~4명 채웁니다(Gobert · Okongwu · Vučević · Clingan급). **그 위는 자유입니다.**
